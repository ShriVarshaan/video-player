# Cinewall keyboard shortcuts and mouse gestures

Letter keys work in upper and lower case.

## Home wall

| Key or gesture | What it does |
|---|---|
| Arrow keys | Move to the next poster. Hold to keep moving. |
| Space | Show the info card for the focused poster. |
| Enter | Open the title page. |
| `/` or Ctrl+F | Open search. |
| Any letter or number | Open search with that character already typed. |
| Click a poster | Open its title page. |
| Hover a poster and rest | Focus it and show its info card. |
| Drag | Pan the wall. It keeps gliding when you let go. |
| Mouse wheel or trackpad | Pan the wall. |
| Shift + wheel | Pan sideways. |

The wall ignores keys while you are typing in a box or using the menu drawer.

## Menu

| Key | What it does |
|---|---|
| Up / Down | Move between menu entries (wraps around). |
| Esc | Close the menu. |

## Title page

| Key | What it does |
|---|---|
| Left / Right | Move between seasons or episodes in a row. |
| Tab | Leave the row. |
| Esc | Go back. |

## Search

| Key | What it does |
|---|---|
| Type | Search. Letters typed while a result has focus go back to the box. |
| Down | From the box, go to the filter chips, then to the results. |
| Arrow keys | Move between results. Up from the top row goes back to the box. |
| Left / Right | Move between chips. |
| Enter | Open the focused result, or the best match when you are in the box. |
| Esc | Clear the box. Press again to close search. |

You can narrow a search with `cast:`, `director:` or `genre:` (for example `cast:"Tom Hanks"`), or by typing a year or a decade.

## Player

| Key or gesture | What it does |
|---|---|
| Space | Play or pause. |
| Left / Right | Back or forward 10 seconds. |
| Up / Down | Volume up or down 5%. The top is 200% (boost). |
| M | Mute or unmute. |
| F | Full screen on or off. |
| C | Next aspect ratio. |
| Shift + C | Back to the file's own aspect ratio. |
| P | Picture in picture on or off. |
| Esc | Back out one step: close a menu or panel, then leave picture in picture, then leave full screen. It never closes the player. Use the X button for that. |
| Click the picture | Play or pause. |
| Double-click the picture | Full screen on or off. |
| Click or drag the seek bar | Jump to that point. |

Arrow keys do not act on the player while the volume slider has keyboard focus. They move the slider instead.

## Subtitles

These need a subtitle to be showing.

| Key | What it does |
|---|---|
| G | Show subtitles earlier by 0.05 s. |
| H | Show subtitles later by 0.05 s. |
| Shift + G / Shift + H | The same, in 0.5 s steps. |
| S | Sync to a line (not in picture in picture). |
| A | Auto sync to the speech in the audio (not in picture in picture). |

### Sync to a line (S)

| Key | What it does |
|---|---|
| Left / Right | Previous or next subtitle line. |
| S or Enter | Sync to the chosen line. |
| Esc | Cancel. |

### Offset panel (opened from the subtitle menu)

| Key | What it does |
|---|---|
| Right / Up | Later by 0.05 s. |
| Left / Down | Earlier by 0.05 s. |
| Shift + arrow | Steps of 0.5 s. |
| Home | Reset the offset to 0. |
| Enter | Close the panel (when the slider has focus). |
| Esc | Close the panel. |

The offset runs from -10 s to +10 s. While the panel is open, the player's own keys do not act.

### Other panels

| Key | What it does |
|---|---|
| Esc | Close the auto sync card (this cancels the sync), style panel or search panel. |
| Up / Down | Move through the items in track menus and the subtitle search results. |

## Picture in picture

Press P (or use the controls) to float the player over other apps.

| Gesture | What it does |
|---|---|
| Drag the picture | Move the window. Works across displays. |
| Drag an edge or corner | Resize the window. |
| Click the picture | Play or pause. |
| Double-click the picture | Return to the full window. |
| P or Esc | Return to the full window. |
